How this stays private

  • The channel key is derived fresh every time you connect (ECDH P-256).
  • Both sides prove they know the pairing key before a single command is sent.
  • Messages are AES-256-GCM with a counter, so replays are rejected.
  • Nothing reaches a cloud service — the phone talks only to your hardware.
