      How the link works

      1. Phone → VPN Your WireGuard/tailnet tunnel carries the app traffic.
      2. ESP32 Dials the agent on TCP 7879, proven with a challenge/response.
      3. Agent → PC Executes only allow-listed commands, rate-limited and audit-logged.
      4. Fallback No network? The ESP32 relay can still power the machine on or off.
